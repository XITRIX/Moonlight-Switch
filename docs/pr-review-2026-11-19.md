# Upstream PR review and LL3 recovery build

Read the public GitHub PR descriptions and the #339 patch directly on 2026-11-19.
These are proposed changes, not measurements from our OLED. Several explicitly
say they have not been tested on a console. Open PRs can be stacked and contain
dependencies; do not apply all of them together.

Open PR listing pages 1–4 and closed pages 1–2 were inspected for relevant
titles. This review did not find a demonstrated Switch OLED NVDEC change that
guarantees Android's reported 1–2 ms decode time. Switch 2 AV1 and decoder timing
changes are not interchangeable with Switch 1 NVTEGRA.

## LL3 scope

The LL2 fixed 3 MiB socket initialization override is removed. Socket service
initialization now uses the original Borealis/libnx policy. Only readback of the
actual SO_RCVBUF remains. This is a conservative rollback after the user reported
stream-start failure; the cause has not been proven by an on-console trace.

Keep latest-frame presentation, decoder-stat reset on reconnect, and existing
lifecycle fixes. Add failed connection stage/code to the start-error dialog and
replace local stage-name indexing with the library's LiGetStageName. No NVDEC
clock, bitrate or encryption changes are included.

Host fixture tests and native Switch cross-compilation validate source behavior
and packaging. A successful stream start, smoothness and input-to-photon latency
still require a device test. Next evidence needed if it fails is the full stage
and code displayed by LL3.
